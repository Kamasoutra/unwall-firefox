Unlisted submission for personal distribution. Independent Firefox companion for https://unwall.app/, not affiliated with that service.

Purpose: detect paywalled articles locally using JSON-LD Article/NewsArticle metadata and visible paywall notices, then navigate the same tab to the external reader at https://unwall.app/<article URL>. Automatic opening is enabled by default and can be paused globally or per site. The popup provides manual opening and return to the publisher without redirect loops.

All executable extension code is included in the XPI as readable, unminified JavaScript. There is no bundler, obfuscation, remote code loading, eval, or runtime dependency in the extension. The npm dependencies are development/test tools and are not packaged. No separate source archive is needed to read or reproduce the extension: the XPI contains the original extension files directly.

Data: article URLs opened in the reader are transmitted to unwall.app by navigation. Browsing activity is declared as required in browser_specific_settings.gecko.data_collection_permissions. Detection stays local. The extension does not send source-page cookies, login credentials, page contents or telemetry. Tracking parameters and fragments are removed. Local/IP addresses and recognized sensitive URL parameters are rejected. Preferences and exclusions are stored in storage.local; one original address per tab is held in storage.session for redirect-loop prevention and removed on tab closure.

Permissions: HTTP/HTTPS hosts for local content-script detection; tabs for current-page URL and navigation; storage for settings and tab-session state; menus for reader actions on pages/links; webNavigation for same-document navigation rescanning.

Testing: Firefox 157.0.1 on macOS, nine unit tests and nine browser scenarios passed; web-ext lint reports no errors, warnings or notices. The real-article checks demonstrate detection/navigation, not guaranteed full-text recovery. Unwall failed to retrieve the complete tested Figaro and Mediapart articles, and the extension does not claim success solely because it redirected a tab.

No account is needed to use the extension or to open Unwall. The privacy policy text is provided separately in mozilla/privacy-policy.txt for attachment to the submission if requested.
